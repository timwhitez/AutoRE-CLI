# AutoRE-CLI v0.1.12

CLI and Agent Skill 0.1.12 ship together. This release includes the latest merged static-evidence fixes: x86 far/system transfers no longer become invented near-call targets; high-byte register and call-result handling preserve evidence; call expressions stay within their control-flow boundaries; Rust name filtering uses namespace evidence; and metadata-only strings no longer become false address-zero string references. Ambiguous relocatable objects retain explicit rejection with an accurate diagnostic.

Five packages are provided: macOS ARM64 and Intel, Linux ARM64 and x86_64, and Windows x86_64. Each contains the matching CLI, Skill, offline installers, source-revision manifest, checksums and dependency licenses. A separate Skill ZIP is also provided. Verify downloads against `SHA256SUMS.release`.

This is a new version, so the managed installer can update a verified 0.1.11 installation. The 0.1.12 Skill requires the matching CLI version. Historical 0.1.11 assets are unchanged.

Binary build source revision: `84744e58a58fab6f49369793757f6ccc2df8fe2c`. Builds use Rust/Cargo 1.97.1 and the locked dependencies. Build-host source paths are remapped. macOS binaries have ad-hoc signatures with verified code-page hashes; they are not Developer ID signed or notarized. Windows is unsigned with a static LLVM-MinGW runtime and zero PE timestamp.

Validation is local on Linux x86_64. Cross-compilation and static validation of the other four platforms do not establish native runtime compatibility. No target, payload or recovered artifact is executed; no paid-model or real-agent evaluation is included. Coverage gaps documented by the static tests remain limits, not new capability claims.
