# AutoRE-CLI v0.1.13

CLI and Agent Skill 0.1.13 ship together. This release includes the merged fixes for signed-relative jump tables ([source #420](https://github.com/timwhitez/auto-re_source/issues/420)), call-result order ([source #421](https://github.com/timwhitez/auto-re_source/issues/421)), and bundle FIFO replacement ([public #64](https://github.com/timwhitez/AutoRE-CLI/issues/64)). Jump-table targets now require a proved LOAD→ADD→JMP path; calls stay at their original position when an intervening assignment has unproved effects; bundle verification rejects a FIFO replacement before reading it.

Five packages are provided: macOS ARM64 and Intel, Linux ARM64 and x86_64, and Windows x86_64. Each package contains the matching CLI and Skill, offline installer, source-revision manifest, checksums, and dependency licenses. A separate Skill ZIP is also provided. Verify downloads against `SHA256SUMS.release`.

This new version allows managed installations to update from 0.1.12. The 0.1.13 Skill requires the matching CLI version. The historical 0.1.12 assets are unchanged.

Binary build source revision: `ff8e115f05d0a437d83c8dcb24f85204c2b049d5`. Builds use Rust/Cargo 1.97.1 and locked dependencies. Build-host source paths are remapped. macOS binaries have ad-hoc signatures with verified code-page hashes; they are not Developer ID signed or notarized. Windows is unsigned with a static LLVM-MinGW runtime and zero PE timestamp.

Validation is local on Linux x86_64. Cross-compilation and static checks of the other four platforms do not establish native runtime compatibility. No target, payload, or recovered artifact is executed.

## 2026-10-21 Skill documentation refresh

This refresh includes the completed [Skill documentation change #419](https://github.com/timwhitez/auto-re_source/issues/419). The root Skill is now 148 lines, with recovery, bundle, continuation and cleanup details loaded when needed. Helper examples use quoted absolute Skill paths and clarify output handling for bundle/spill actions.

All five CLI binaries remain byte-for-byte identical to the original v0.1.13 release. Their version, build source revision, signatures and provenance are unchanged. The existing release tags are unchanged. The five platform archives and standalone Skill ZIP now include the updated Skill; their archive checksums have changed, so use the refreshed `SHA256SUMS.release`. The Skill documentation comes from [source 4c18cf2](https://github.com/timwhitez/auto-re_source/commit/4c18cf2c6500696d6578764a5c1074f4a0f36f01) / [public 9ac1bce](https://github.com/timwhitez/AutoRE-CLI/commit/9ac1bce8329b33286c2c0955a38cf9e4a8f4c152).

The CLI and Skill version remain 0.1.13. Existing managed 0.1.13 installations still reject a same-version Skill content change. To adopt this documentation refresh, download and extract the refreshed platform package, then use the existing Skill-only uninstall/reinstall flow. For Codex, run from the extracted package:

```sh
python3 scripts/autore_distribution.py uninstall --skill-only --agents codex
python3 scripts/autore_distribution.py install --skill-only --agents codex
```

Use `py -3` on Windows; use `--agents trae` for a managed Trae installation. This flow preserves the installed CLI. Modified managed Skills remain protected by the existing refusal rules; no force or bypass option is required for an unmodified installation. Fresh installs include the refreshed Skill directly.

Independent documentation review passed on the linked commits, with 70 focused helper tests and 11 command checks. These checks do not measure model benefit or establish native cross-platform execution.
