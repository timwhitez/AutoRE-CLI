# AutoRE-CLI v0.1.8

This release builds all five supported binaries locally from source revision
`762b83581916e233371e40474af80f5c27338f92` and updates the CLI and Agent Skill to 0.1.8.

- Installer updates bind the original managed files to their identities and
  restrict rollback to files owned by the current transaction.
- Continuation handling rejects malformed control JSON values, permits bounded
  continuation after a recorded timeout, and exposes selectable data-reference
  follow-up stages.
- The release packager freezes one checksum-verified public snapshot before
  creating platform archives.
- The Linux x86-64 cross-build records pinned Zig, LLVM-MinGW and rcodesign
  provenance; macOS binaries are ad-hoc signed and statically verified.

The release contains macOS arm64/x86-64, Linux arm64/x86-64 and Windows x86-64
archives plus a standalone Agent Skill ZIP. Compilation and verification ran
locally. Cross-platform format, architecture, provenance, signature and checksum
checks are static; native macOS and Windows execution was not tested on this
Linux host. Windows is not Authenticode signed and macOS is not notarized.

Download the matching `AutoRE-CLI-0.1.8-<platform>` archive or
`AutoRE-CLI-0.1.8-auto-re-skill.zip`, then verify `SHA256SUMS.release`.
