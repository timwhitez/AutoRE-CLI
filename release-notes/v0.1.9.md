# AutoRE-CLI v0.1.9

All five CLI binaries are compiled locally from source revision
`d7be29ba6ecf47c0199020b0140dc3ae1edfedbd` with pinned Rust/Cargo 1.97.1 and the existing locked dependencies.
The CLI and Agent Skill both use version 0.1.9.

- Existing `function`, `slice-function`, `dump-il`, `dump-cfg` and `data-xrefs`
  help now explains selection, address units, paging and effective budgets.
- The optional `read_result.py` provides bounded, stateless, read-only views of
  existing JSON. Continuation offsets require the original input hash; it does
  not invoke analysis or validate the source's evidence claims.
- Selected analysis, its original fallback and Go/forwarder enhancement reuse
  one request-local input snapshot. Normalized and chosen-slice views retain
  their actual analysis source. Selection, budgets, warnings and evidence gates
  are preserved. Controlled measurements reduced repeated input I/O but did
  not establish a stable wall-time improvement.
- Go funcval detection accepts the actual MLIL dereference form while rejecting
  overwritten or ambiguous register sources.

The release contains macOS ARM64/x86-64, Linux ARM64/x86-64 and Windows x86-64
archives, a standalone Agent Skill ZIP, and `SHA256SUMS.release`.
Builds and verification run locally. Linux x86-64 is the native host;
other targets receive cross-build/static acceptance, not native runtime
certification. macOS binaries are ad-hoc signed and their code-page hashes
verified; they are not Developer ID signed or notarized. Windows binaries are
unsigned and retain the static runtime and zero PE timestamp contract.
No GitHub Actions, analyzed targets or target-derived artifacts are executed.

Download the matching `AutoRE-CLI-0.1.9-<platform>` archive, verify it against
`SHA256SUMS.release`, extract it and run its verifier before installation.
Rerun the installer from the new archive to upgrade managed 0.1.8 installations;
CLI and Skill identities advance together. Unmanaged files, managed drift,
same-version repacks and downgrades remain fail-closed. A published release
does not automatically change an existing user's installation.
