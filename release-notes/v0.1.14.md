# AutoRE-CLI v0.1.14

CLI and Agent Skill 0.1.14 ship together, with locally rebuilt binaries for macOS ARM64 and Intel, Linux ARM64 and x86_64, and Windows x86_64. Each platform package includes the matching Skill, offline installer, source-revision manifest, dependency licenses and checksums. A separate Skill ZIP is also provided. Verify downloads against `SHA256SUMS.release`.

## Changes

- Add bounded embedded-header inspection and explicit, single-layer gzip extraction. Extracted bytes are never executed.
- Preserve control-flow edges and block coverage in HLIL, and correct signature-derived ABI parameter hints.
- Keep function pagination stable when discovery budgets increase; reject non-regular batch inputs before hashing.
- Include optional ELF x86-64 register-provenance evidence. This does not prove source-language arguments, calling conventions or runtime behavior.
- Upgrade iced-x86 to 1.22.0 and include Windows artifact handling, helper launch and stack-size fixes.
- Update the Skill request-identity contract for all 36 CLI commands and the new options. Identity recognition does not grant execution permission; existing continuation admission boundaries remain in force.
- Preserve public installer and checksum safety fixes, including root-only marker exemptions.

## Provenance and validation

Binary build source revision: `f8c3e6b22d14cf366ae5b50c2a292ddac1d725a7`. All five binaries were built locally on macOS ARM64 with Rust/Cargo 1.97.1 and locked dependencies. Linux builds use Zig 0.15.2; Windows uses LLVM-MinGW 20260616 UCRT. Build-host paths are remapped.

- Rust workspace tests: 5,256 passed, 190 ignored by the maintained suite, zero failed.
- Source distribution CI: 371 tests, three platform-dependent skips.
- Public distribution CI: 357 tests passed; macOS ARM64 installation, CLI/Skill pairing, controlled-object static analysis, uninstall and archive checks passed.
- Formatting, static-safety checks and their mutation tests, cross-toolchain inventory regressions, release licensing and agent-harness checks passed.
- All five binary formats/architectures and release inventories were checked. macOS ad-hoc signatures were verified. Windows has a static LLVM-MinGW runtime and a zero PE timestamp.

Native runtime checks cover macOS ARM64 only. Cross-compilation and static checks do not establish native Linux, Windows or Intel macOS runtime compatibility. macOS binaries are not Developer ID signed or notarized; Windows binaries are not Authenticode signed. No analyzed sample, extracted payload or target-derived artifact was executed.

## Upgrade

Download the matching 0.1.14 platform archive, extract it, then run `./verify.sh` and `./install.sh` (or the documented Python equivalents on Windows). Use the same installation destinations as the existing managed installation. CLI and Skill versions must match. Managed content drift remains a blocking error; no forced replacement is required for an unchanged 0.1.13 installation. Previous release tags and assets remain unchanged.
