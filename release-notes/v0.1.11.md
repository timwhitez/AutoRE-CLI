# AutoRE-CLI v0.1.11 — rebuilt 2026-10-16

This replaces the v0.1.11 release assets with fresh release builds from source
revision `ad385697c11e1dc758f939654d6ff114bef49fcc`. CLI and Agent Skill versions remain 0.1.11.
The previous binaries were built from `b7379a2f2267fe4471373a7bfa4b113122ed1395`.
Existing installations must be reinstalled to receive the refreshed binaries and
helpers. Verify the new archives against the accompanying `SHA256SUMS.release`;
checksums from the earlier v0.1.11 publication no longer identify these assets.

The release includes the current main branch fixes for x86 jump-table operand
widths and register clobbers, Go stack-address provenance, continuation JSON
input safety, and verification-receipt admission within cleanup reader budgets.
The `describe`, JSON diagnostics, `kinds-v1` result roots, bounded artifact
readers and paired 0.1.11 Skill remain included.

Five platform packages are provided: macOS ARM64 and Intel, Linux ARM64 and
x86_64, and Windows x86_64. Each includes the matching binary, Agent Skill,
offline installers, provenance manifest, checksums and third-party notices.
A separate Skill ZIP is also available.

Builds use pinned Rust/Cargo 1.97.1 and the existing Cargo.lock. Release
validation is performed locally on Linux. The release process checks the full
Rust workspace, four core feature combinations, Clippy, static safety, license
and agent-harness contracts, source layout, distribution and public helper tests,
Skill metadata, distribution integrity and deterministic platform archives.
The trusted Linux x86_64 CLI receives its side-effect-free version probe.

The other four platform binaries receive cross-compilation and static format
validation, without native runtime certification. macOS binaries are ad-hoc
signed with verified code-page hashes; they are not Developer ID signed or
notarized. Windows is unsigned, uses static LLVM-MinGW runtime linkage and has
a zero PE timestamp. No analyzed sample or target-derived artifact is executed.
No real-agent/model evaluation is claimed.
