# AutoRE-CLI v0.1.10

All five CLI binaries are compiled locally from source revision
`c96114e38ee63aad391136846fdcc7138668d772` with pinned Rust/Cargo 1.97.1 and the existing locked dependencies.
The CLI and Agent Skill both use version 0.1.10.

- Continuation receipts share bounded producer, admission and prior-reader
  rules. Preflight checks the derived encoded upper bound before analysis;
  accepted receipts round-trip through the real reader without truncation.
- Help for `function`, `slice-function`, `dump-il` and `dump-cfg` distinguishes
  the requested default of 2000 functions from the internal discovery floor
  of 32768. Smaller explicit values do not lower that floor; output paging and
  instruction budgets remain separate. `data-xrefs` retains its own contract.
- Address focus resolution defers Symbol-only section and language preparation.
  Address normalization, Symbol recovery, normal loader metadata, warnings and
  selected output facts are preserved. No end-to-end speed or RSS gain is claimed.

The release contains macOS ARM64/x86-64, Linux ARM64/x86-64 and Windows x86-64
archives, a standalone Agent Skill ZIP, and `SHA256SUMS.release`.
Builds and verification run locally. Linux x86-64 is the native host;
other targets receive cross-build/static acceptance, not native runtime
certification. macOS binaries are ad-hoc signed with verified code-page hashes;
they are not Developer ID signed or notarized. Windows binaries are unsigned,
with a static LLVM-MinGW runtime and zero PE timestamp.
No GitHub Actions, analyzed targets or target-derived artifacts are executed.

Download the matching `AutoRE-CLI-0.1.10-<platform>` archive, verify it against
`SHA256SUMS.release`, extract it and run its verifier before installation.
Rerun the installer from the new archive to upgrade managed 0.1.9 installations;
CLI and Skill identities advance together. Unmanaged files, managed drift,
same-version repacks and downgrades remain fail-closed. A published release
does not automatically change an existing user's installation.
